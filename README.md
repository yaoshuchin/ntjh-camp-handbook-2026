# 南投縣立南投國民中學 115學年度 二年級隔宿露營行動手冊（去個資版）

本專案依據南投國中 115 學年度二年級戶外教育隔宿露營資料（尖山埤山訓探索・野營炊事・團結成長之旅，兩天一夜）打造之全方位響應式（RWD）行動數位簡報手冊網站。

專為手機、平板、大型觸控螢幕與電腦放映優化，讓隨隊師長、全體同學與家長在露營活動期間能隨時隨地離線查詢行程、帳篷住宿、野炊幹部分工、野營技能、山訓探索、行李清單與生活公約。

---

## 🌟 核心功能特色

1. **🖥️ 網頁式簡報模式 (`index.html`)**
   - 採用成熟的 1280×720 DSLab Lesson Deck 引擎。
   - **投影片簡報模式 (Present Mode)**：鍵盤方向鍵或手機滑動翻頁，自動等比縮放全螢幕適配。
   - **閱讀捲動模式 (Reading Mode)**：所有幻燈片垂直展開，便於快速翻閱與檢索。
   - **目錄總覽 (TOC Modal)**：一鍵展開章節目錄，隨點即跳轉。
   - 包含 24 頁精美投影片：活動總覽、尖山埤營地介紹、活動基地與交通指引、兩日時間表、蒙古包六大搭帳步驟、無痕山林LNT、生火技巧與野炊控火、戰術偽裝與定向、童軍八大繩結、臺灣六大毒蛇辨識與「五要五不」急救、營火晚會儀式歌謠、高空垂降、PA解手結團隊跳繩、人工攀岩、水彈生存遊戲、獨木橋平衡、打包清單、營規公約、帳篷住宿分配總表、野炊小隊編組總表。

2. **📱 互動手冊網頁版 (`app.html`)**
   - **📅 行程總覽**：第一天與第二天完整時間軸，含餐食安排與各節點重點指引。
   - **⛺ 帳篷住宿即時速查**：全校 27 頂帳篷（男13/女14），支援輸入同學姓名、座號、班級（201~207）、帳號（男第1帳、女第2帳）即時秒查，提供一鍵列印查帳名冊功能。
   - **🍳 野炊小隊即時速查**：全校 15 個野炊小隊，完整標註小隊長、副小隊長、大廚、二廚、伙夫、水夫、事務與隊員分工。
   - **🔍 學生名冊資料庫**：全校 106 位同學，支援性別、素食、室長、班級篩選。
   - **🏕️ 野營常識教學專題**：六人蒙古包搭設拆收步驟、無痕山林 (LNT) 七大準則。
   - **⚜️ 童軍技能教育實作**：生火技巧、火媒棒、面部迷彩偽裝、自然方向辨識、童軍八大繩結圖解、臺灣六大毒蛇圖鑑與五要五不急救處置、營火晚會拜火詞與歌曲。
   - **🧗 山訓探索教育指引**：高空垂直垂降操作姿勢、PA探索解手結心法、團隊跳繩默契、人工抱石攀岩三點不動一點動、水彈生存遊戲戰術與安全鐵律、獨木橋橫渡平衡。
   - **🎒 行前行李打包清單**：四分類必備清單，支援互動勾選、即時打包進度百分比，狀態自動儲存於瀏覽器 LocalStorage，重新整理不遺失。
   - **⚠️ 營規生活須知**：營地生活紀律、內務晨檢規範、生活競賽計分標準、緊急應變聯絡網絡與醫護站指引。

3. **🔒 個資安全去識別化 (Privacy Masking)**
   - 全體 106 位同學、7 班導師與行政主管人名第二個字均以「O」進行去識別化遮罩（如 江O婷、林O嫻、黃O月、李O、劉O彥），確保公開發布合規安全。

---

## 🚀 本機啟動方式

- **方式一（推薦）**：直接雙擊點擊 `start.bat`，自動啟動本機 HTTP 伺服器並在瀏覽器開啟。
- **方式二**：直接以瀏覽器開啟 `index.html`（簡報模式）或 `app.html`（手冊網頁版），完全支援本機離線瀏覽。
